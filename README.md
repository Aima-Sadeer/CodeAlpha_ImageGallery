# Image Gallery

A responsive and interactive **Image Gallery** website developed using **HTML, CSS, and JavaScript**. This project provides a clean and modern interface for browsing and viewing different categories of images with interactive features.

## Features

* Responsive image gallery
* Animal image collection
* Architecture image collection
* Nature image collection
* Travel image collection
* Image zoom functionality
* Previous and next navigation buttons
* Clean and attractive user interface
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Explore the Image Gallery and its interactive features.
